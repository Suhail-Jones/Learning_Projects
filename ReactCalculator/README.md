A basic calculator that allows the user to compute using addition, subtraction, multiplication, and division. Built with React and Vite.

A rebuild of the CalculatorApp project, made to practice React fundamentals: useState, lifting state into a shared parent, passing callbacks down through props, and conditional rendering.

Features:
- Addition, subtraction, multiplication, and division
- Decimal support for each operand
- Negative numbers
- Operator replacement (pressing a second operator swaps the first)
- Clear (CE)
- Results rounded to 4 decimal places to avoid floating point noise
- Invalid input shows a message instead of crashing

Run locally:

    npm install
    npm run dev

Then open http://localhost:5173

Status: Complete.
